# UniVerse

UniVerse is a campus connect and social lifestyle application specifically designed for students of Bayero University Kano (BUK).

## Project Overview

UniVerse aims to bridge the gap between students, providing a platform for social interaction, campus updates, and lifestyle integration. Unlike traditional academic tools, UniVerse focuses on the **social and lifestyle** aspects of student life at BUK.

**Key Focus Areas:**
*   **Campus Connect:** Stay updated with campus events and news.
*   **Social Interaction:** Connect with fellow BUK students.
*   **Student Lifestyle:** Features tailored to the daily life of a student on campus.

> [!IMPORTANT]
> UniVerse is a social application. It is NOT an academic book-related platform.

## Getting Started

### Prerequisites
*   Flutter SDK
*   Android Studio / VS Code
*   Android/iOS Emulator or Physical Device

### Installation
1.  Clone the repository.
2.  Run `flutter pub get` to install dependencies.
3.  Run `flutter run` to start the application.

## Tech Stack
*   **Framework:** [Flutter](https://flutter.dev)
*   **Language:** [Dart](https://dart.dev)
*   **Theming:** Custom AppTheme (Material Design)
